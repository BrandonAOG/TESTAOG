Each set must be 1/0 or larger, same length, material and insulation (310.10(G)).
Round up to next breaker size
240.4(B) lets a wire use the next standard breaker above its ampacity, for example 4/0 Al (180A) on a 200A breaker. Off by default, so the wire is always at least the breaker size. Never use it on receptacle branch circuits with cord-and-plug loads.

NEC 2023: 240.4, 240.6, 310.12, Table 310.16, Table 310.15(B)(1), Table 310.15(C)(1), 310.10(G), 110.14(C), Table 250.122. Check voltage drop on long runs. Always verify with the AHJ.
