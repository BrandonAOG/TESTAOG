More options (pressure drop, elevation)
Bigger drop = smaller pipe, but less pressure at the generator. The inlet check below uses this number.
Only changes the generator's kW output, not the pipe size.

Galvanized (Sch 40) and PE (SDR 11, ½" SDR 9) are calculated with the NFPA 54 / IFGC 402.4 sizing equations at your exact length. These are the same equations the code tables come from, and they match Tables 402.4(2), (5) and (21). Low-pressure runs use a 0.5" WC drop unless you change it. Elevated runs use the drop shown in the dropdown. NG: SG 0.60, 1,000 BTU/ft³. LP: SG 1.52, 2,516 BTU/ft³. CSST / TracPipe use approximate manufacturer tables, so confirm with the EHD chart for the product you're installing. Ordinary fittings are covered by the code method; add equivalent length for unusually fitting-heavy runs. Generator fuel use is from Generac spec sheets. Tank runtime assumes 80% fill. Verify with a licensed gas fitter and the AHJ.
