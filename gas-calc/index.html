📋 Code Reference

NFPA 54 (2024) Chapter 6 capacity tables for Sch 40 steel, PE and CSST, plus the Gastite / FlashShield and TracPipe manufacturer charts the calculator uses: natural gas and propane.

Galvanized (Sch 40) and PE (SDR 11, ½" SDR 9) are calculated with the NFPA 54 / IFGC 402.4 sizing equations at your exact length. These are the same equations the code tables come from, and every result is held to the published NFPA 54 (2024) Tables 6.2.1 / 6.3.1 (IFGC Table 402.4). Low-pressure runs use a 0.5" WC drop unless you change it. Elevated runs use the drop shown in the dropdown. NG: SG 0.60, 1,000 BTU/ft³. LP: SG 1.52, 2,516 BTU/ft³. CSST is sized from the manufacturer's own charts: Gastite / FlashShield Section 7 (Jan 2013) and TracPipe CounterStrike FGP-001US (Apr 2022). Length is rounded up to the next chart row; a drop between two charts uses the larger chart scaled down, never above the published values. Ordinary fittings are covered by the code method; add equivalent length for unusually fitting-heavy runs. Generator fuel use is from Generac spec sheets. Tank runtime assumes 80% fill. Verify with a licensed gas fitter and the AHJ.

This calculator solves the same equations for flow at your exact length: Q = 2313 × D2.623 × (ΔH ÷ (Cr × L))0.541 (low) and Q = 2237 × D2.623 × ((P₁² − P₂²) × Y ÷ (Cr × L))0.541 (high, × 0.95). Those constants come out slightly under the code's (about 0.6%), so the result stays on the safe side.
Heating values used: NG 1,000 BTU/ft³ (SG 0.60) · LP 2,516 BTU/ft³ (SG 1.52).
NFPA 54 6.1.2 · LONGEST LENGTH METHODSize every section using the length from the point of delivery (meter or regulator) to the most remote outlet, with the load that section carries.
NFPA 54 6.1.3 · BRANCH LENGTH METHODSize the main run using the longest run. Size each branch using the length from the point of delivery to the most remote outlet on that branch.
NFPA 54 6.1.4 · HYBRID PRESSUREElevated-pressure piping is sized to the most remote line pressure regulator. Piping after each regulator is sized from that regulator to the most remote outlet it serves. That's how this calculator sizes each side of a 2 PSI or two-stage system separately.
NFPA 54 6.2.1 / 6.3.1 · TABLESNatural gas: Tables 6.2.1(a)–(x). Propane: Tables 6.3.1(a)–(m). Use them with one of the methods above. Pick the table matching the gas, pipe material, inlet pressure and allowed pressure drop.
READING A TABLEUse the length row equal to or longer than your run, then the first size whose capacity is equal to or greater than the load. Never round the length down.
UNITSNG tables are in ft³/hr (CFH). At 1,000 BTU/ft³, 1 CFH ≈ 1,000 BTU/hr. Propane tables are in thousands of BTU/hr. Some NG tables (like 6.2.1(c)) are printed in thousands of BTU/hr.
CSSTCSST tables are by EHD (flow designation), not trade size. Each brand's ½", ¾", etc. has its own EHD. Match it from the manufacturer's install guide. This calculator uses Gastite/Wardflex and TracPipe charts.
FLORIDANatural gas piping in Florida is enforced under the Florida Building Code – Fuel Gas, which numbers its sizing tables 402.4(x). They're built from the same equations, but verify with the AHJ.
